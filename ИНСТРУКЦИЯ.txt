КАК УСТАНОВИТЬ ПРОФИЛЬ 846 DIGITAL

1. Откройте репозиторий:
   https://github.com/846Digital/846Digital

2. Удалите текущий файл README.md или откройте его для редактирования.

3. Загрузите из этого архива:
   - README.md — в корень репозитория;
   - папку assets — целиком в корень репозитория.

Структура должна выглядеть так:

846Digital/
├── README.md
└── assets/
    └── hero.svg

4. Нажмите Commit changes.

5. Откройте:
   https://github.com/846Digital

Оформление автоматически появится на главной странице профиля.

Важно:
- index.html внутрь профильного README встроить нельзя;
- профиль GitHub отображает Markdown, картинки и GIF;
- полноценный HTML-сайт остаётся по адресу https://846digital.github.io/.
